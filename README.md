# Lecture Homework Week 08 - Tuesday

For this lecture homework, you will prepare to understand the concepts of an Embedded Operating System (EOS).

## The Homework

The reading assignment for today's lecture contains no code. However, for the next lecture, we will begin looking at the code for an embedded operating system. Because this course is only 10 weeks long, we do not have time to cover all the chapters in the book. As a quick refresher: Chapter 5 discusses process management, Chapter 6 covers memory management, and Chapter 7 covers user mode processes and system calls. All of these concepts are critical to understanding any operating system.

To better prepare for the rest of Chapter 8, it is important to review these foundational pillars. For this homework, you will look back at these previous chapters, read the specified sections, and explain the following concepts **in your own words**.

### The Process Concept

Section 5.2 of the book describes what a process is and defines its basic C struct. Read this section, and then in your `homework_template.docx` file, define what a process is and provide a brief description of each member of the `PROC` structure defined in the text.

### The Memory Management Concept

Sections 6.1 and 6.2 discuss process address space and memory management. Read these two sections, and then define what a virtual address is and what role the MMU plays with respect to virtual addresses. Again, write your answers in `homework_template.docx`.

### The User Mode and System Call Concepts

Sections 7.1 through 7.3 describe what user mode processes are, and Section 7.7 discusses process management. Read these sections, and then briefly describe what a user mode process is and what a system call does in relation to user mode. Finally, read Section 7.7 and briefly describe how a process is created.
